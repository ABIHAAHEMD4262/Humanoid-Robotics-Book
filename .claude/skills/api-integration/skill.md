# API Integration Skill

Integrate external APIs with comprehensive error handling, caching, and retry logic.

## When to use
- Integrating translation APIs
- Adding any external API to the project
- Need robust error handling and retries
- Implementing API caching

## What it does
1. Researches and compares API options
2. Implements API client with TypeScript
3. Adds error handling and retry logic
4. Implements caching strategy
5. Adds rate limiting
6. Creates usage documentation
7. Sets up environment variables

## Example usage
User: "Integrate LibreTranslate API for Urdu translation"

Agent will:
- Research LibreTranslate API documentation
- Create TypeScript API client
- Add error handling with retry logic
- Implement in-memory caching
- Add rate limiting
- Create .env.example entry
- Document API usage

## Output
- API client TypeScript file
- Error handling utilities
- Cache implementation
- Documentation
- Environment variable setup
- Usage examples
