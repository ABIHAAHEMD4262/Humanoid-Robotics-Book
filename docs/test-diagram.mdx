## Features Demonstrated

1. **Lazy Loading**: The image loads only when scrolling into view
2. **Accessibility**: Proper alt text and ARIA labels
3. **Responsive**: Adapts to different screen sizes
4. **Error Handling**: Shows error state if image fails to load
5. **Loading State**: Skeleton shimmer while loading
