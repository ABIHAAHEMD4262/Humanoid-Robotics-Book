# Appendices

Welcome to the appendices section! Here you'll find supplementary resources, guides, and reference materials to support your Physical AI journey.

## What's Included

This section provides practical resources and troubleshooting guides to help you succeed:

- **Hardware Buyer's Guide (2025)**: Comprehensive guide to selecting hardware for Physical AI development
- **Economy Jetson Kit BOM**: Bill of materials for a budget-friendly Jetson-based setup
- **Cloud-Only Path**: Instructions for cloud-based development using AWS g5/g6 instances
- **Devcontainer & Docker Setup**: Reproducible development environment configuration
- **Troubleshooting FAQ**: Common issues and their solutions

## Who Should Use This Section?

The appendices are designed for:
- Readers setting up their development environment for the first time
- Those encountering technical issues during hands-on projects
- Budget-conscious learners exploring hardware options
- Developers preferring cloud-based development over local hardware

## How to Navigate

Each appendix is self-contained and can be referenced independently. Use the sidebar to jump directly to the resource you need.
