# 2025 Hardware Buyer's Guide

Comprehensive guide to selecting hardware for Physical AI development in 2025.

## Budget Tiers

### Economy Path ($700-$1500)
- NVIDIA Jetson Orin Nano Dev Kit
- USB camera
- Basic sensors
- Cloud GPU credits for heavy workloads

### Mid-Range Path ($1500-$5000)
- NVIDIA Jetson AGX Orin
- Intel RealSense D455
- Unitree Go2 (quadruped for testing)
- Desktop workstation with RTX 4070

### Professional Path ($5000-$20000)
- NVIDIA Jetson AGX Orin with 64GB RAM
- Unitree G1 humanoid robot
- Workstation with RTX 4090
- LiDAR sensors
- High-fidelity cameras

## Component Breakdown

### Compute Platform
- Jetson for edge deployment
- Workstation for development and training
- Cloud GPUs for heavy simulation

### Sensors
- Cameras (RGB, Depth, Stereo)
- LiDAR (2D/3D)
- IMU
- Force/Torque sensors

### Robot Platforms
- Simulation-only (no physical robot needed)
- Quadrupeds (Unitree Go2)
- Humanoids (Unitree G1)

## Recommendations by Use Case

**Student/Hobbyist**: Economy path + cloud GPU
**Researcher**: Mid-range path
**Professional/Commercial**: Professional path

## Where to Buy

- NVIDIA Developer Store

## Future-Proofing

Consider:
- GPU compute capability
- RAM and storage expandability
- Software ecosystem support
- Community and documentation
