## Understanding Gaits

A simple walking gait has phases:

1. **Lift Phase**: Lift one leg
2. **Swing Phase**: Move leg forward
3. **Plant Phase**: Place foot down
4. **Support Phase**: Other leg lifts

For a full walk cycle, both legs go through these phases. They're offset by 50%.

### Gait Timing

Let's say one step takes 1 second:
- Left leg lifts at 0.0s
- Left leg swings at 0.25s
- Left leg plants at 0.5s
- Right leg lifts at 0.5s
- Right leg swings at 0.75s
- Right leg plants at 1.0s

Then it repeats.

## The Code

Here's the complete gait publisher:

```python title="gait_publisher/gait_publisher_node.py"
# Library: rclpy v3.3.7
# Last updated: 2025-12-05
# Tested on: ROS 2 Humble, Python 3.10

import rclpy
from rclpy.node import Node
from sensor_msgs.msg import JointState
import math

class GaitPublisher(Node):
    def __init__(self):
        super().__init__('gait_publisher')

        # Create publisher for joint states
        self.publisher = self.create_publisher(
            JointState,
            'joint_commands',
            10
        )

        # Gait parameters
        self.step_period = 2.0  # 2 seconds per step
        self.step_height = 0.05  # 5cm lift
        self.step_length = 0.1  # 10cm forward

        # Timer for publishing (50 Hz)
        self.timer = self.create_timer(0.02, self.timer_callback)
        self.time = 0.0

        self.get_logger().info('Gait Publisher started')

    def timer_callback(self):
        # Create joint state message
        msg = JointState()
        msg.header.stamp = self.get_clock().now().to_msg()

        # Joint names (simplified humanoid)
        msg.name = [
            'left_hip_pitch',
            'left_knee',
            'left_ankle',
            'right_hip_pitch',
            'right_knee',
            'right_ankle'
        ]

        # Calculate joint positions
        phase = (self.time % self.step_period) / self.step_period

        # Left leg (starts at phase 0)
        left_phase = phase
        left_hip, left_knee, left_ankle = self.calculate_leg_joints(left_phase)

        # Right leg (starts at phase 0.5)
        right_phase = (phase + 0.5) % 1.0
        right_hip, right_knee, right_ankle = self.calculate_leg_joints(right_phase)

        # Assign positions
        msg.position = [
            left_hip,
            left_knee,
            left_ankle,
            right_hip,
            right_knee,
            right_ankle
        ]

        # Publish
        self.publisher.publish(msg)

        # Increment time
        self.time += 0.02

    def calculate_leg_joints(self, phase):
        """
        Calculate joint angles for one leg based on gait phase.
        Phase goes from 0.0 to 1.0 for one complete step.
        """
        if phase < 0.5:
            # Swing phase (leg in air)
            # Lift leg, swing forward
            swing_progress = phase * 2.0  # 0.0 to 1.0

            # Hip swings forward
            hip = -0.3 + (0.6 * swing_progress)

            # Knee bends to lift foot
            knee = 0.5 * math.sin(swing_progress * math.pi)

            # Ankle compensates
            ankle = -0.2 * math.sin(swing_progress * math.pi)

        else:
            # Support phase (leg on ground)
            # Extend leg, push back
            support_progress = (phase - 0.5) * 2.0  # 0.0 to 1.0

            # Hip extends back
            hip = 0.3 - (0.6 * support_progress)

            # Knee straightens
            knee = 0.0

            # Ankle stays neutral
            ankle = 0.0

        return hip, knee, ankle


def main(args=None):
    rclpy.init(args=args)
    node = GaitPublisher()

    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

Let's break down the key parts.

## Code Explanation

### Initialization

```python
self.publisher = self.create_publisher(
    JointState,
    'joint_commands',
    10
)
```

We publish JointState messages. These contain joint names and positions.

### Timer Callback

```python
self.timer = self.create_timer(0.02, self.timer_callback)
```

We publish at 50 Hz (every 0.02 seconds). This gives smooth motion.

### Phase Calculation

```python
phase = (self.time % self.step_period) / self.step_period
```

Phase goes from 0.0 to 1.0 for each step. At 1.0, it wraps back to 0.0.

### Leg Offset

```python
left_phase = phase
right_phase = (phase + 0.5) % 1.0
```

Right leg is 0.5 phase behind left leg. When left leg lifts, right leg is planted.

### Joint Calculation

The `calculate_leg_joints()` function has two phases:

**Swing Phase** (0.0 to 0.5):
- Leg lifts
- Swings forward
- Uses sine wave for smooth motion

**Support Phase** (0.5 to 1.0):
- Leg on ground
- Extends backward
- Provides support

### Example 2: Understanding Phase

**Type**: Scenario

**Context**: Imagine a clock. The hand goes around once per hour. At 12, it starts over.

**Explanation**: Phase works the same way. 0.0 is the start of a step (like 12 o'clock). 0.5 is halfway through (like 6 o'clock). 1.0 wraps back to 0.0 (like going from 11:59 to 12:00). The sine wave creates smooth transitions, just like how a pendulum swings smoothly.

**Takeaway**: Phase is a repeating cycle from 0 to 1. Math functions like sine create smooth, natural motion.

## Improvements

This is a basic gait. Here are ways to improve it:

### 1. Add Balance

Real robots need to shift weight. Add torso lean:

```python
# Shift torso toward support leg
torso_lean = 0.1 * math.sin(phase * 2 * math.pi)
```

### 2. Add Arm Swing

Arms swing opposite to legs:

```python
# Arms swing opposite to legs for balance
left_arm = -left_hip * 0.5
right_arm = -right_hip * 0.5
```

### 3. Make It Configurable

Add parameters for step length, height, and speed:

```python
self.declare_parameter('step_length', 0.1)
step_length = self.get_parameter('step_length').value
```

### 4. Add Turning

Modify hip yaw joints to turn while walking:

```python
# Add turning
turn_angle = 0.1 * self.turning_direction
hip_yaw = turn_angle * phase
```

## Common Issues

### Issue 1: Robot Falls Over

**Problem**: Simulated robot tips and falls.

**Solution**: Check your URDF inertia values. Incorrect mass distribution causes falls. Also, start with slower gaits.

### Issue 2: Joints Move Too Fast

**Problem**: Motion looks jerky or violent.

**Solution**: Increase `step_period`. Use 3.0 or 4.0 seconds per step. Speed up gradually.

### Issue 3: Feet Penetrate Ground

**Problem**: Feet go through the floor in simulation.

**Solution**: Adjust ankle joint calculations. Make sure support leg ankle angle keeps foot flat.
