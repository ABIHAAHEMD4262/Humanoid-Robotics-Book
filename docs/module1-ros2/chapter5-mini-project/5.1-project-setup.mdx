# 5.1 Project Setup & Package Creation

:::tip Estimated Time
**15 minutes**
:::

Welcome to Phase 1! Before we can make our humanoid walk, we need to set up a solid foundation. In this section, you'll create a proper ROS 2 package with all the necessary structure and dependencies.

## Project Requirements & Goals

Let's be clear about what we're building:

### Functional Requirements
- Generate walking gait trajectories for 6 leg joints (3 per leg)
- Publish joint positions at 50 Hz (real-time control rate)
- Support configurable parameters (step height, stride length, frequency)
- Provide smooth, continuous motion suitable for visualization

### Technical Requirements
- ROS 2 Humble (or compatible distribution)
- Python 3 implementation using rclpy
- Standard message types (sensor_msgs/JointState)
- Proper package structure following ROS 2 conventions

### Success Criteria
✅ Package builds without errors
✅ All dependencies are properly declared
✅ Directory structure is clean and organized
✅ Initial test node runs successfully

## Step 1: Create Your Workspace (If Needed)

If you already have a workspace from previous chapters, navigate to its `src` directory:

cd ~/your_workspace/src

## Step 2: Create the Package

Now let's create our `gait_publisher` package with all necessary dependencies:

```bash
ros2 pkg create gait_publisher \
  --build-type ament_python \
  --dependencies rclpy sensor_msgs std_msgs geometry_msgs \
  --description "Walking gait trajectory publisher for humanoid robots" \
  --license Apache-2.0 \
  --maintainer-name "Your Name" \
  --maintainer-email "your.email@example.com"
```

:::info What Just Happened?
- `--build-type ament_python`: Creates a Python package (not C++)
- `--dependencies`: Automatically adds required packages to `package.xml`
- `--description`: Adds metadata for documentation
- `--license`: Sets open-source license (Apache 2.0 is ROS standard)
:::

You should see output like:
```
going to create a new package
package name: gait_publisher
destination directory: /home/user/humanoid_ws/src
...
```

## Step 5: Configure package.xml

Open `package.xml` and let's verify/enhance it:

```xml title="package.xml"
<?xml version="1.0"?>
<?xml-model href="http://download.ros.org/schema/package_format3.xsd" schematypens="http://www.w3.org/2001/XMLSchema"?>
<package format="3">
  <name>gait_publisher</name>
  <version>1.0.0</version>
  <description>Walking gait trajectory publisher for humanoid robots</description>
  <maintainer email="your.email@example.com">Your Name</maintainer>
  <license>Apache-2.0</license>

  <!-- Build dependencies -->
  <buildtool_depend>ament_python</buildtool_depend>

  <!-- Runtime dependencies -->
  <depend>rclpy</depend>
  <depend>sensor_msgs</depend>
  <depend>std_msgs</depend>
  <depend>geometry_msgs</depend>

  <!-- Additional dependencies for visualization -->
  <exec_depend>robot_state_publisher</exec_depend>
  <exec_depend>joint_state_publisher</exec_depend>
  <exec_depend>rviz2</exec_depend>
  <exec_depend>xacro</exec_depend>

  <!-- Testing dependencies -->
  <test_depend>ament_copyright</test_depend>
  <test_depend>ament_flake8</test_depend>
  <test_depend>ament_pep257</test_depend>
  <test_depend>python3-pytest</test_depend>

  <export>
    <build_type>ament_python</build_type>
  </export>
</package>
```

:::tip Dependency Types
- `<buildtool_depend>`: Tools needed to build the package
- `<depend>`: Required at both build and runtime
- `<exec_depend>`: Only needed at runtime
- `<test_depend>`: Only needed for testing
:::

## Step 6: Configure setup.py

Open `setup.py` and modify it to include our additional directories:

```python title="setup.py"
from setuptools import find_packages, setup
import os
from glob import glob

package_name = 'gait_publisher'

setup(
    name=package_name,
    version='1.0.0',
    packages=find_packages(exclude=['test']),
    data_files=[
        ('share/ament_index/resource_index/packages',
            ['resource/' + package_name]),
        ('share/' + package_name, ['package.xml']),
        # Include launch files
        (os.path.join('share', package_name, 'launch'),
         glob(os.path.join('launch', '*launch.[pxy][yma]*'))),
        # Include config files
        (os.path.join('share', package_name, 'config'),
         glob(os.path.join('config', '*.yaml'))),
        (os.path.join('share', package_name, 'config'),
         glob(os.path.join('config', '*.rviz'))),
        # Include URDF files
        (os.path.join('share', package_name, 'urdf'),
         glob(os.path.join('urdf', '*.urdf'))),
        (os.path.join('share', package_name, 'urdf'),
         glob(os.path.join('urdf', '*.xacro'))),
    ],
    install_requires=['setuptools'],
    zip_safe=True,
    maintainer='Your Name',
    maintainer_email='your.email@example.com',
    description='Walking gait trajectory publisher for humanoid robots',
    license='Apache-2.0',
    tests_require=['pytest'],
    entry_points={
        'console_scripts': [
            # We'll add our node entries here in later steps
            # 'gait_publisher_node = gait_publisher.gait_publisher_node:main',
        ],
    },
)
```

:::info What's Important Here?
The `data_files` section tells ROS 2 to install our launch files, configs, and URDF files so they're accessible after building. The glob patterns automatically include all matching files.
:::

- **Simple geometry**: Cylinders for legs, boxes for torso and feet
:::

## Step 8: Create a Placeholder Node

Let's create a simple test node to verify our setup works:

```python title="gait_publisher/test_node.py"
#!/usr/bin/env python3
"""
Simple test node to verify package setup.
This will be replaced with the actual gait publisher in later steps.
"""

import rclpy
from rclpy.node import Node


class TestNode(Node):
    """Minimal node for testing package setup."""

    def __init__(self):
        super().__init__('test_node')
        self.get_logger().info('Test node started successfully!')
        self.get_logger().info('Package setup is working correctly.')

        # Create a timer that prints every 2 seconds
        self.timer = self.create_timer(2.0, self.timer_callback)
        self.counter = 0

    def timer_callback(self):
        """Periodic callback to show node is alive."""
        self.counter += 1
        self.get_logger().info(f'Test node alive: {self.counter} ticks')


def main(args=None):
    rclpy.init(args=args)
    node = TestNode()

    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

## Troubleshooting Common Issues

### Issue: "Package not found" after building

**Solution**: Make sure you sourced the workspace:
```bash
source ~/humanoid_ws/install/setup.bash
```

### Issue: colcon build fails with Python errors

**Solution**: Check that `__init__.py` exists in all package directories:
```bash
ls gait_publisher/__init__.py
ls gait_publisher/math/__init__.py
```

### Issue: URDF file not found

**Solution**: Verify the glob patterns in `setup.py` match your file names and rebuild:
```bash
colcon build --packages-select gait_publisher --symlink-install
```

### Issue: "No executable found" when running test_node

**Solution**: Check entry_points in `setup.py` and rebuild. Make sure the module path is correct.
