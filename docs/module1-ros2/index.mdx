# Module 1 – The Robotic Nervous System (ROS 2)

Welcome to Module 1! Here, we dive into ROS 2 (Robot Operating System 2), the industry-standard middleware framework that serves as the nervous system for modern robots.

## What is ROS 2?

ROS 2 is an open-source robotics middleware suite that provides the communication infrastructure, tools, and libraries needed to build complex robot applications. Think of it as the "operating system" that allows different parts of your robot to talk to each other.

## What You'll Learn

In this module, we will cover:

- **ROS 2 Core Concepts**: Nodes, Topics, Services, and Actions
- **Python Development with rclpy**: Building ROS 2 applications in Python
- **Robot Description with URDF/Xacro**: Defining humanoid robot models
- **Package Management**: Creating, building, and launching ROS 2 packages
- **Practical Application**: Building a walking gait publisher for humanoid robots

## Learning Objectives

By the end of this module, you will be able to:

1. Understand the ROS 2 communication architecture
2. Create and manage ROS 2 nodes, topics, services, and actions
3. Develop ROS 2 applications using Python and rclpy
4. Define robot models using URDF and Xacro
5. Build and launch complete ROS 2 packages
6. Implement a walking gait publisher for a humanoid robot

## Prerequisites

- Completion of Module 0 (Foundations)

- Familiarity with Linux command line (we'll provide guidance)

## Mini-Project

This module culminates in a hands-on mini-project: **Building a Walking Gait Publisher in Python**. You'll create a ROS 2 node that generates and publishes joint trajectories for humanoid walking.
