# Chapter 3: Robot Description with URDF & Xacro

**Estimated Chapter Time**: 45 minutes
**Prerequisites**: Chapter 1 - Core Communication Patterns, Chapter 2 - Python Development
**Difficulty**: Intermediate

## Chapter Overview

You know how to make ROS 2 programs communicate. Now learn how to describe robot structure.

URDF (Unified Robot Description Format) is XML for describing robots. Xacro makes URDF easier by adding macros and variables. This chapter teaches you to define humanoid robot models.

## Learning Objectives

By the end of this chapter, you will:

- Understand URDF structure and syntax
- Define robot links and joints
- Use Xacro macros for reusable components
- Create collision and visual geometries
- Add inertial properties for physics
- Visualize robots in RViz
- Follow best practices for robot modeling

## Why URDF & Xacro?

URDF provides:
- **Standard Format**: Used across ROS ecosystem
- **Simulation Ready**: Works with Gazebo, Isaac Sim, etc.
- **Visualization Support**: Direct RViz integration
- **Kinematic Tree**: Clear parent-child relationships

Xacro adds:
- **Code Reuse**: Write once, use many times
- **Parameterization**: Easy robot variants
- **Maintainability**: Cleaner, more organized descriptions
- **Math Operations**: Calculate derived values

## Common Patterns You'll Learn

### Pattern 1: Basic Link Definition
```xml
<link name="base_link">
  <visual>
    <geometry>
      <box size="0.5 0.3 0.1"/>
    </geometry>
  </visual>
</link>
```

### Pattern 2: Joint Connection
```xml
<joint name="shoulder_joint" type="revolute">
  <parent link="base_link"/>
  <child link="upper_arm"/>
  <origin xyz="0 0 0.1" rpy="0 0 0"/>
  <axis xyz="0 1 0"/>
  <limit lower="-1.57" upper="1.57" effort="100" velocity="1.0"/>
</joint>
```

### Pattern 3: Xacro Macro
```xml
<xacro:macro name="leg" params="prefix reflect">
  <link name="${prefix}_thigh">
    <visual>
      <geometry>
        <cylinder radius="0.05" length="0.4"/>
      </geometry>
    </visual>
  </link>
</xacro:macro>
```
