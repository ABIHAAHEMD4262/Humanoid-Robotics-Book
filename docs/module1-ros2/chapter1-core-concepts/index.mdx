## Chapter Overview

ROS 2 has four fundamental building blocks for robot communication. Nodes. Topics. Services. Actions. These are the vocabulary that lets robots talk to each other.

This chapter teaches you each communication pattern. You'll understand when to use each one. You'll see how they work together in real robot systems.

## Learning Objectives

By the end of this chapter, you will:

- Understand what nodes are and why robots use them
- Know how to use topics for streaming data
- Use services for request-response communication
- Implement actions for long-running tasks
- Choose the right communication pattern for any scenario

## Why This Matters

These four patterns are the foundation of every ROS 2 robot. Master them now. Everything else builds on these concepts.

A humanoid robot uses all four:
- **Nodes** separate camera, planning, and motor control
- **Topics** stream sensor data continuously
- **Services** query current state quickly
- **Actions** execute walking and manipulation tasks
