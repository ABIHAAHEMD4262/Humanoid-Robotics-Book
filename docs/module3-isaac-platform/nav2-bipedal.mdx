Adapt the Nav2 navigation stack for humanoid bipedal robots.

## Overview

Nav2 provides:
- Path planning
- Obstacle avoidance
- Recovery behaviors
- Lifecycle management

## Challenges for Bipedal Robots

Unlike wheeled robots, bipedal robots must consider:
- Footstep planning
- Dynamic balance
- Gait execution
- Terrain adaptation

## Configuration

### Custom Costmap Layers

```yaml
costmap:
  footprint: [[0.15, 0.1], [0.15, -0.1], [-0.15, -0.1], [-0.15, 0.1]]
  inflation_layer:
    inflation_radius: 0.5
  static_layer:
    enabled: true
```
