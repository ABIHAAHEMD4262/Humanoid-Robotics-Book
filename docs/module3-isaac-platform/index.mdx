# Module 3 – The AI-Robot Brain (NVIDIA Isaac™ Platform)

Welcome to Module 3! Here, we explore the NVIDIA Isaac™ Platform – a comprehensive suite of tools, libraries, and frameworks for building AI-powered robotic systems.

## What is the NVIDIA Isaac Platform?

The Isaac Platform brings together photorealistic simulation (Isaac Sim), hardware-accelerated perception (Isaac ROS), and AI-driven navigation to create intelligent, autonomous robots. Think of it as the "brain" that enables robots to perceive, understand, and navigate their world.

## What You'll Learn

In this module, we will cover:

- **Isaac Sim (Omniverse)**: Photorealistic simulation and synthetic data generation
- **Isaac ROS**: Hardware-accelerated perception pipelines (VSLAM, 3D reconstruction)
- **Nav2 for Bipedal Robots**: Adapting the navigation stack for humanoid locomotion
- **Domain Randomization**: Techniques for sim-to-real transfer
- **Practical Application**: Autonomous navigation in cluttered indoor environments

## Learning Objectives

By the end of this module, you will be able to:

1. Set up and use Isaac Sim for photorealistic robot simulation
2. Generate synthetic training data for perception models
3. Implement hardware-accelerated perception with Isaac ROS
4. Configure Nav2 for bipedal navigation
5. Apply domain randomization for sim-to-real transfer
6. Build an autonomous indoor navigation system for humanoid robots

## Prerequisites

- Completion of Modules 1 and 2
- NVIDIA RTX GPU (40-series recommended) or access to cloud GPU instances
- Understanding of perception and navigation concepts (covered in Module 0)

## Mini-Project

This module's hands-on project: **Autonomous Navigation in a Cluttered Indoor Scene**. You'll implement full autonomy for a humanoid robot navigating through furniture, obstacles, and dynamic environments.

## Key Technologies

- **Isaac Sim**: Physics-accurate, photorealistic simulation
