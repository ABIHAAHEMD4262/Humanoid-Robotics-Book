Module 2 – The Digital Twin (Gazebo & Unity)

Welcome to Module 2! In this module, we explore digital twins – virtual replicas of physical robots that allow us to simulate, test, and validate robotic systems before deploying them in the real world.

What is a Digital Twin?​

A digital twin is a virtual representation of a physical system that mirrors its behavior, physics, and sensor data. For robotics, digital twins enable safe, cost-effective development and testing in simulated environments.

What You'll Learn​

In this module, we will cover:

  • Gazebo Simulation: Setting up Gazebo Ignition/Harmonic for physics-accurate simulation
  • URDF to SDF Conversion: Transforming robot models for simulation
  • Sensor Simulation: Implementing LiDAR, depth cameras, and IMUs in simulation
  • Unity Integration: Using Unity for high-fidelity visualization and human-robot interaction
  • Practical Application: Creating a realistic apartment environment with sensor streaming

Learning Objectives​

By the end of this module, you will be able to:

  1. Set up and configure Gazebo for humanoid robot simulation
  2. Convert URDF robot models to SDF format
  3. Simulate realistic sensors (LiDAR, cameras, IMU)
  4. Integrate Unity for photorealistic visualization
  5. Create custom simulation environments
  6. Stream and visualize sensor data from your digital twin
  7. Successfully spin up a complete humanoid digital twin in under 30 minutes

Prerequisites​

  • Completion of Module 1 (ROS 2)
  • Understanding of robot description formats (URDF)
  • Moderate system resources (RTX 40-series GPU recommended)

Mini-Project​

This module features a capstone mini-project: Building a Realistic Apartment Environment with Sensor Data Streaming. You'll create a fully functional digital twin of a humanoid robot in a home environment.

Success Criteria​

By the end of this module, you should be able to:

  • Spin up a complete humanoid digital twin in under 30 minutes
  • Visualize sensor data in real-time
  • Control the robot within the simulated environment

Let's bring your robot to life in the virtual world!
