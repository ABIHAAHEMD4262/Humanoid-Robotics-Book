## Overview

Sensors are critical for robot perception and navigation. In this section, we'll add and configure:
- **LiDAR**: For 2D/3D environment mapping
- **Depth Cameras**: For visual perception and object detection
- **IMU (Inertial Measurement Unit)**: For orientation and acceleration data

## LiDAR Sensor Configuration

### Adding a 2D LiDAR to Your Robot

```xml
<sensor name="lidar" type="gpu_lidar">
  <pose>0 0 0.3 0 0 0</pose>
  <topic>/lidar</topic>
  <update_rate>10</update_rate>
  <lidar>
    <scan>
      <horizontal>
        <samples>640</samples>
        <resolution>1</resolution>
        <min_angle>-3.14159</min_angle>
        <max_angle>3.14159</max_angle>
      </horizontal>
    </scan>
    <range>
      <min>0.1</min>
      <max>30.0</max>
      <resolution>0.01</resolution>
    </range>
    <noise>
      <type>gaussian</type>
      <mean>0.0</mean>
      <stddev>0.01</stddev>
    </noise>
  </lidar>
  <always_on>true</always_on>
  <visualize>true</visualize>
</sensor>
```

## Depth Camera Configuration

### Adding an RGBD Camera

```xml
<sensor name="depth_camera" type="depth">
  <pose>0.1 0 0.4 0 0 0</pose>
  <camera>
    <horizontal_fov>1.5708</horizontal_fov>
    <image>
      <width>640</width>
      <height>480</height>
    </image>
    <clip>
      <near>0.1</near>
      <far>10.0</far>
    </clip>
  </camera>
  <always_on>1</always_on>
  <update_rate>30</update_rate>
  <visualize>true</visualize>
  <topic>/depth_camera</topic>
</sensor>
```

### Processing Depth Data in ROS 2

```python title="depth_processor.py"
# Library: rclpy v3.3.7, cv_bridge v3.2.1
# Last updated: 2025-12-05
# Tested on: ROS 2 Humble, Python 3.10

import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Image
from cv_bridge import CvBridge
import cv2

class DepthProcessor(Node):
    def __init__(self):
        super().__init__('depth_processor')
        self.subscription = self.create_subscription(
            Image,
            '/depth_camera/depth/image_raw',
            self.depth_callback,
            10
        )
        self.bridge = CvBridge()

    def depth_callback(self, msg):
        depth_image = self.bridge.imgmsg_to_cv2(msg, desired_encoding='32FC1')
        # Process depth data here
        cv2.imshow('Depth', depth_image / 10.0)  # Normalize for display
        cv2.waitKey(1)

def main():
    rclpy.init()
    node = DepthProcessor()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()
```

### Reading IMU Data in ROS 2

```python title="imu_reader.py"
# Library: rclpy v3.3.7
# Last updated: 2025-12-05
# Tested on: ROS 2 Humble, Python 3.10

import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Imu

class IMUReader(Node):
    def __init__(self):
        super().__init__('imu_reader')
        self.subscription = self.create_subscription(
            Imu,
            '/imu',
            self.imu_callback,
            10
        )

    def imu_callback(self, msg):
        self.get_logger().info(f'Orientation: {msg.orientation}')
        self.get_logger().info(f'Angular velocity: {msg.angular_velocity}')
        self.get_logger().info(f'Linear acceleration: {msg.linear_acceleration}')
```

## Performance Optimization

- Reduce sensor update rates for better performance
- Use GPU-accelerated sensors when available
- Simplify sensor noise models if not needed
- Limit the number of simultaneous sensors
